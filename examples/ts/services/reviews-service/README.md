# reviews-service

Generated by `xenosis create service`.

## Run

```bash
pnpm --filter reviews-service dev
```

Service starts on port **4020** and reloads on file changes via native OS filesystem events (fsevents / inotify). On Docker or a mounted/network filesystem where those don't fire, force polling: `CHOKIDAR_USEPOLLING=true pnpm --filter reviews-service dev`.

## Try it

```bash
curl http://localhost:4020/healthcheck
# → "reviews-service is healthy!"

curl http://localhost:4020/api/v1/example
# → { "message": "Hello, world! — from reviews-service" }

curl -X POST http://localhost:4020/api/v1/example \
  -H 'content-type: application/json' \
  -d '{"name":"Alice"}'
# → { "message": "Hello, Alice! — from reviews-service" }
```

## Add a database

1. Run `xenosis create schema <name>` to scaffold a schema package.
2. Add a connector + schema binding to `xenosis.config.json`:
   ```jsonc
   "connectors": {
     "psqlMain": { "type": "postgres", "url": "postgresql://..." }
   },
   "schemas": {
     "mainDb": { "package": "@example/<schema-name>", "connector": "psqlMain" }
   }
   ```
3. Inject `mainDb` into a service or repository class.

## Add a peer (call another service)

1. Run `xenosis create api <name>` to scaffold a peer API package.
2. Add a peer binding to `xenosis.config.json`:
   ```jsonc
   "peers": {
     "<name>": {
       "package": "@example/<name>-api",
       "transport": "http",
       "baseUrl": "http://localhost:4000"
     }
   }
   ```
3. Inject `PeerClient<XApi>` into a service.
