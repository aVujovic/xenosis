## JSDoc tips

The service is plain JavaScript, but JSDoc comments give your editor the
same autocomplete you'd get from TypeScript. Pattern:

```js
/**
 * @typedef {import('@xenosisorg/xenosis-core').ILogger} ILogger
 */

export default class MyService {
  /** @param {{ logger: ILogger }} deps */
  constructor({ logger }) {
    this.logger = logger;
  }
}
```
