## Add a database

1. Run `xenosis create schema <name>` to scaffold a schema package.
2. Add a connector + schema binding to `xenosis.config.json`:
   ```jsonc
   "connectors": {
     "psqlMain": { "type": "postgres", "url": "postgresql://..." }
   },
   "schemas": {
     "mainDb": { "package": "{{appScope}}/<schema-name>", "connector": "psqlMain" }
   }
   ```
3. Inject `mainDb` into a service or repository class.

## Add a peer (call another service)

1. Run `xenosis create api <name>` to scaffold a peer API package.
2. Add a peer binding to `xenosis.config.json`:
   ```jsonc
   "peers": {
     "<name>": {
       "package": "{{appScope}}/<name>-api",
       "transport": "http",
       "baseUrl": "http://localhost:4000"
     }
   }
   ```
3. Inject `PeerClient<XApi>` into a service.
