├── {{sharedModulesDir}}/    ← cradle singletons available in every service

└── {{servicesDir}}/         ← runnable services

## Get started

```bash
# Create your first schema package, API contract, and service:
xenosis create schema psql-main
xenosis create api billing
xenosis create service users

# Add a cradle singleton available in every service:
xenosis create shared-module whitelabel

# Run everything in parallel:
xenosis dev
```
